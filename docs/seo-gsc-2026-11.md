## Findings

1. **Generic head terms can't rank yet.** Merge/combine/join images: 159 query variants, 565 impressions at
   position 90 (/tools/merge-images: 664 at 86). Resize JPG/PNG/GIF pages: 838 impressions at 74–86. On-page
   issues were fixed in the October review (docs/seo-gsc-2026-10.md); the gap is domain age and links. No rewrite.
2. **Sourced exam pages reach page 1 quickly.** /tools/upessc-photo position 4.1 (2 clicks from 15 impressions),
   upsssc-photo 5.0, dsssb-photo 8.8, jee-main-photo 11. Exam queries: "3/4 photo size upsc" 2, "rrb signature
   resize 60 140 pixels" 5, "upsc photo size in cm" 9, "railway signature size in pixels" 11, "rrb je photo size"
   17, "rrb je signature format" 30, "railway group d photo size" 100 (no page).
3. **"Image size in KB" is close to page 1.** 127 KB queries, 311 impressions at 61, but "change image size kb"
   (13.7), "resize the picture in kb" (14), "resize image by kb" (12), "resize image size in kb" (15), while
   /tools/resize-image-to-kb averages 49. Confirm the ranking URL in Search Console.
4. Smaller: WebP is less contested ("resize webp" 34, "webp size converter" 13); "compress image size to 200kb"
   6 and "200 kb photo" 18 against /tools/200kb-photo at 53; Indonesian, Hindi and Russian queries appear in small
   numbers. Search appearance is empty (expected: FAQ rich results are no longer shown for most sites).

## Changes made (4 Nov 2026)

- **Applications open now** block on the homepage and /tools/application-photos, from
  `lib/requirements/open-applications.ts`. Each entry is dated from its official notice and disappears the day
  after it closes (India time); both pages use `revalidate = 86400`, so they stay static and are rebuilt daily.
- /tools/resize-image-to-kb: intro and description use "change image size in KB"; keyword map gains "change image
  size in kb" and "resize image by kb".
- /tools/application-photos: title and description list the exams it now covers (RRB, JEE Main, UP TGT).
- New exam pages are added only when the online application stays open at least 20 days after publishing, so
  Google can index the page before the window closes.
